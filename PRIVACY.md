# Privacy Policy

Fairstack Coreview runs entirely on your computer.

- **No data is collected or sent to Fairstack or any third party.** The app has no analytics, tracking or accounts.
- **Local files.** Settings, history of measurements, snapshots and pairing data are stored on your computer in the application data folder. You can delete them at any time (History → *Clear history*, or remove the app data folder).
- **Local network (optional).** If you turn on *Mobile* in the app, the app listens on your local network so that your paired phone can read the computer's status. Traffic is encrypted, and only phones you paired with a one-time code can connect. It is off by default. Remote commands are off by default too.
- **Hardware access.** To read sensors, the app runs a helper process and, on Windows, can install the open-source PawnIO driver after you confirm. FPS measurement (Windows) uses the bundled PresentMon tool and only measures frame timing of the application in focus.
- **Downloads.** The optional PawnIO driver installation uses the Windows Package Manager (`winget`), which downloads it from its publisher.

Questions about privacy: open an issue in this repository.
